## How reference cases are used

Each case asks the same questions:

**What problem appeared?**

**Why did the obvious approach fail?**

**What architectural mechanism was introduced?**

**What trade-offs remained?**

**What can be generalized safely?**

**What should be measured?**

External companies and research are identified explicitly. Their outcomes are not presented as personal experience.
